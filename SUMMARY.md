# MEDAI - Резюме проекта

## Что было создано

Полнофункциональный веб-интерфейс для системы регистрации и логина пользователей с поддержкой ИИН (Индивидуальный идентификационный номер) или номера телефона.

## Технологический стек

- **Backend**: Flask 3.1.2
- **БД**: SQLite с SQLAlchemy ORM
- **Аутентификация**: Flask-Login
- **Валидация**: WTForms
- **Безопасность**: Werkzeug (хеширование паролей)
- **Frontend**: HTML5 + Bootstrap 5

## Установка и запуск

### Шаг 1: Установка зависимостей
```bash
pip install -r requirements.txt
```

### Шаг 2: Создание БД и тестового пользователя
```bash
python manage.py create_demo
```

### Шаг 3: Запуск приложения
```bash
python run.py
```

Откройте браузер: **http://localhost:5000**

## Тестовый пользователь

| Поле | Значение |
|------|----------|

## База данных

### Таблица users

| Поле | Тип | Описание |
|------|-----|---------|
| id | Integer | Уникальный идентификатор |
| iin | String(12) | Индивидуальный номер (может быть NULL) |
| phone | String(20) | Номер телефона (может быть NULL) |
| email | String(120) | Email (обязательно, уникально) |
| password_hash | String(255) | Хешированный пароль |
| full_name | String(120) | Полное имя пользователя |
| created_at | DateTime | Дата и время регистрации |

## API маршруты

| Маршрут | Метод | Требуется вход | Описание |
|---------|-------|---|---------|
| `/` | GET | Нет | Главная страница (перенаправляет) |
| `/register` | GET, POST | Нет | Страница и обработка регистрации |
| `/login` | GET, POST | Нет | Страница и обработка входа |
| `/logout` | GET | Да | Выход из системы |
| `/users` | GET | Да | Список всех пользователей (с пагинацией) |
| `/user/<id>` | GET | Да | Информация о конкретном пользователе |

## Команды управления (manage.py)

```bash
# Инициализировать пустую базу данных
python manage.py init_db

# Создать БД и тестового пользователя
python manage.py create_demo

# Просмотреть всех пользователей
python manage.py list_users

# Очистить всю БД (требует подтверждения)
python manage.py reset_db
```

## Production развертывание

Для использования в production:

1. Установите WSGI сервер:
   ```bash
   pip install gunicorn
   ```

2. Запустите приложение:
   ```bash
   gunicorn -w 4 'app:create_app()'
   ```

3. Используйте reverse proxy (nginx, Apache)

4. Включите HTTPS (SSL/TLS)

5. Используйте PostgreSQL вместо SQLite

6. Установите переменные окружения для SECRET_KEY
