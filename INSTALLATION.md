# MEDAI - Система регистрации и логина

## Что было создано

Полнофункциональное веб-приложение на Flask с системой регистрации и логина.

### Основные компоненты:

1. **Backend (Flask)**
   - Фреймворк: Flask 3.1.2
   - ОРМ: SQLAlchemy 2.0.46
   - Валидация форм: WTForms 3.2.1
   - Аутентификация: Flask-Login 0.6.3
   - Безопасность: Werkzeug 3.1.5

2. **База данных**
   - SQLite (medai.db)
   - Таблица users с полями:
     - id (Integer, Primary Key)
     - iin (String, Unique, Optional) - Индивидуальный идентификационный номер
     - phone (String, Unique, Optional) - Номер телефона
     - email (String, Unique, Required) - Email
     - password_hash (String, Required) - Хешированный пароль
     - full_name (String, Required) - Полное имя
     - created_at (DateTime) - Дата регистрации

3. **Фронтенд**
   - Bootstrap 5 для стилизации
   - Отзывчивый дизайн (mobile-friendly)
   - 5 HTML шаблонов:
     - base.html - базовый шаблон
     - login.html - страница входа
     - register.html - страница регистрации
     - users.html - список пользователей
     - user_detail.html - информация о пользователе

4. **Функциональность**
   - Регистрация через ИИН или телефон
   - Безопасный логин с хешированием паролей
   - Просмотр списка всех пользователей
   - Просмотр информации о каждом пользователе
   - Защита маршрутов (требуется аутентификация)
   - Сессии и управление пользователями
   - Валидация данных на клиенте и сервере

## Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Создание БД и тестового пользователя
```bash
python manage.py create_demo
```

### 3. Запуск приложения
```bash
python run.py
```

Откройте браузер: http://localhost:5000

### Маршруты

| Маршрут | Метод | Аутентификация | Описание |
|---------|-------|---|---------|
| `/` | GET | Нет | Главная страница |
| `/register` | GET, POST | Нет | Регистрация |
| `/login` | GET, POST | Нет | Вход |
| `/logout` | GET | Да | Выход |
| `/users` | GET | Да | Список пользователей |
| `/user/<id>` | GET | Да | Информация о пользователе |

## Команды управления

```bash
# Инициализировать пустую БД
python manage.py init_db

# Создать тестового пользователя
python manage.py create_demo

# Просмотреть всех пользователей
python manage.py list_users

# Очистить всю БД (требует подтверждения)
python manage.py reset_db
```

## Особенности безопасности

- Пароли хешируются с использованием werkzeug.security.generate_password_hash
- CSRF защита на всех формах (Flask-WTF)
- Валидация email с использованием email-validator
- ИИН валидируется как 12 цифр
- Номер телефона валидируется как минимум 10 цифр
- Сессии управляются Flask-Login
- SQL injection защита через SQLAlchemy ORM

## Развертывание

Для production:

1. Измените SECRET_KEY в app/__init__.py
2. Установите FLASK_ENV=production
3. Используйте production WSGI сервер (например, Gunicorn):
   ```bash
   pip install gunicorn
   gunicorn -w 4 'app:create_app()'
   ```
4. Настройте reverse proxy (nginx или Apache)
5. Используйте PostgreSQL вместо SQLite
