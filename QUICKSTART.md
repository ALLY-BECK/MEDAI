# Быстрый старт MEDAI

## Установка

1. Убедитесь, что у вас установлен Python 3.8+
2. Перейдите в директорию проекта
3. Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск приложения

### Вариант 1: Использование run.py (рекомендуется)

```bash
python run.py
```

### Вариант 2: Использование app.py

```bash
python app.py
```

Приложение будет доступно по адресу: **http://localhost:5000**

## Инициализация базы данных и создание тестового пользователя

```bash
python manage.py create_demo
```

Это создаст БД и добавит тестового пользователя:
- Email: `test@example.com`
- Пароль: `password123`
- ИИН: `12345678901`

## Управление БД

### Просмотр всех пользователей
```bash
python manage.py list_users
```

### Инициализировать пустую БД
```bash
python manage.py init_db
```

### Очистить БД (осторожно!)
```bash
python manage.py reset_db
```

## Основные страницы

- **Главная**: http://localhost:5000/
- **Регистрация**: http://localhost:5000/register
- **Вход**: http://localhost:5000/login
- **Список пользователей**: http://localhost:5000/users (требует входа)

## Тестирование

### Шаг 1: Регистрация нового пользователя
1. Перейдите на http://localhost:5000/register
2. Выберите "По ИИН" или "По номеру телефона"
3. Заполните форму:
   - Полное имя: любое имя
   - ИИН/Телефон: 12345678901 (если ИИН) или +77777777777 (если телефон)
   - Email: your@email.com
   - Пароль: любой пароль (минимум 6 символов)
4. Нажмите "Зарегистрироваться"

### Шаг 2: Вход в систему
1. Перейдите на http://localhost:5000/login
2. Введите один из:
   - Email: your@email.com
   - ИИН: 12345678901 (если регистрировались через ИИН)
   - Телефон: +77777777777 (если регистрировались через телефон)
3. Введите пароль
4. Нажмите "Войти"

### Шаг 3: Просмотр пользователей
1. После входа перейдите на http://localhost:5000/users
2. Просмотрите список всех пользователей
3. Нажмите "Подробнее" на любого пользователя для просмотра подробной информации

## Проблемы?

### Проблема: "port 5000 already in use"
```bash
python run.py --port 5001
```

### Проблема: "ImportError: cannot import name 'create_app'"
Убедитесь, что вы находитесь в правильной директории и установили зависимости.

### Проблема: Ошибка БД
Попробуйте переинициализировать БД:
```bash
python manage.py reset_db
python manage.py create_demo
```
