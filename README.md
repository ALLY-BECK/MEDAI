# MEDAI - Система регистрации и логина

Это Flask приложение для регистрации и логина пользователей с поддержкой ИИН (Индивидуальный идентификационный номер) или номера телефона.

## Особенности

- ✅ Регистрация через ИИН или номер телефона
- ✅ Безопасное хранение паролей (хеширование с Werkzeug)
- ✅ База данных SQLite для хранения данных пользователей
- ✅ Система логирования и сессий (Flask-Login)
- ✅ Валидация данных (WTForms)
- ✅ Красивый интерфейс (Bootstrap 5)
- ✅ Просмотр списка всех пользователей
- ✅ Детальная информация о каждом пользователе

## Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск приложения

```bash
python run.py
```

Приложение будет доступно по адресу: `http://127.0.0.1:5000`

## Использование

### Регистрация

1. Перейдите в раздел "Регистрация"
2. Выберите способ регистрации (ИИН или телефон)
3. Заполните все поля:
   - Полное имя
   - ИИН (12 цифр) ИЛИ номер телефона
   - Email
   - Пароль (минимум 6 символов)
4. Нажмите "Зарегистрироваться"

### Логин

1. Перейдите в раздел "Вход"
2. Введите один из следующих вариантов:
   - Email
   - ИИН (если регистрировались через ИИН)
   - Номер телефона (если регистрировались через телефон)
3. Введите пароль
4. Нажмите "Войти"

### Просмотр пользователей

После входа вы сможете:

1. Просмотреть список всех зарегистрированных пользователей
2. Посмотреть подробную информацию о каждом пользователе
3. Увидеть информацию о способе регистрации

## База данных

База данных создается автоматически при первом запуске приложения.

### Таблица `users`

| Поле | Тип | Описание |
|------|-----|---------|
| id | INTEGER | Уникальный идентификатор |
| iin | VARCHAR(12) | Индивидуальный идентификационный номер (опционально) |
| phone | VARCHAR(20) | Номер телефона (опционально) |
| email | VARCHAR(120) | Email (обязательно) |
| password_hash | VARCHAR(255) | Хешированный пароль |
| full_name | VARCHAR(120) | Полное имя |
| created_at | DATETIME | Дата и время регистрации |

## Маршруты приложения

| Маршрут | Метод | Описание |
|---------|-------|---------|
| `/` | GET | Главная страница |
| `/register` | GET, POST | Регистрация нового пользователя |
| `/login` | GET, POST | Вход в систему |
| `/logout` | GET | Выход из системы |
| `/users` | GET | Список всех пользователей |
| `/user/<id>` | GET | Информация о конкретном пользователе |

## Безопасность

- Все пароли хешируются с помощью Werkzeug.security
- Используется CSRF защита (Flask-WTF)
- Сессии защищены с помощью Flask-Login
- Email валидируется автоматически
- ИИН должен содержать ровно 12 цифр
- Номер телефона должен содержать минимум 10 цифр
